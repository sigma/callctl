Which Chat window this key follows. Any is the default and needs no configuration — with one account signed in, it is always right. With two, pick one per key: the binding is deliberately not assigned by connection order, which depends on which window opened first and would silently swap work and personal between sessions.

Overrides the account name shown on the key. Left empty, the key shows the account's domain with its TLD stripped — arbora, not arbora.partners, which is cramped to unreadable at key size.

The Chrome profile directory to launch into, so the right account's Chat opens. It is the folder name under your Chrome user-data directory — Default, Profile 1, … — shown as Profile Path on chrome://version.

Pressing a dark key launches the installed Chat app. The ID is configuration, not computed — the documented derivation yields a different value from the installed app's actual ID. Find it on chrome://web-app-internals (or, on macOS, as CrAppModeShortcutID in the app shim's Info.plist). Left empty, pressing opens Chat in a tab instead.
